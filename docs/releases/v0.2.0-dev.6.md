# v0.2.0-dev.6

新增多个自有 Codex 账号的保存与默认账号切换。在后台“账号连接”添加账号并各自完成官方设备授权；添加不会覆盖原账号或改变默认，点击“设为默认”选择使用的账号。所有现有 API 密钥、模型目录及 Responses/Chat 使用默认账号。

支持重新授权与确认移除单个账号，最多保存32个。请求、流式生成或刷新进行中不能切换或使用新版移除；忙时明确提示，原请求继续。移除默认后需显式选择其他账号，不自动轮询或故障切换。

旧单账号首次升级自动登记为默认，保留现有加密凭据、API密钥、代理与Access配置。无需新Secret。Node安装包沿用原环境文件和完整数据目录；Worker沿用原ACCOUNT命名空间及ADMIN_API_KEY。不要重复旧密钥迁移流程。

回退须恢复同版本完整存储与代码；旧程序无法管理新增账号索引，不能让旧程序写入后直接重升级并宣称数据完全兼容。
