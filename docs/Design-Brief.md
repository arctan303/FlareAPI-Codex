# FlareAPI 管理后台设计规范

适用范围：CONSOLE-NET-001 的现有后台重组，2026-09-07。目标是管理员快速完成连接、测试、管理密钥和排查调用；保留米白底与深绿主色，不引入新的品牌或前端框架。

## 信息架构与交互

登录页只显示登录入口及必要状态；按用户最新明确要求，表单与必要说明组成居中紧凑卡片，桌面水平并合理垂直居中，小屏保留16px边距。去掉过大宣传标题和干扰性的英文字样，标题约22–26px、正文/标签14–16px，字号层级稳定、间距统一；保留普通管理员口令表单；ACCESS-ENTRY-001用户确认方案（已实现、本地验证并随v0.2.0-dev.3发布）：登录页位于/admin/login，后台位于/admin/，根路径整页重定向登录入口；CF的整页门禁负责先行登录，普通密钥表单不增加CF按钮或折叠提示。登录后显示管理导航。六区为概览（账号/额度摘要与快捷入口）、账号连接（授权生命周期）、模型测试（模型/思考程度/对话）、API 密钥（列表及可折叠创建表单）、调用日志（筛选/分页/详情）、设置（Access 与日志记录设置、命令行网络配置指引）。每次只展示当前区域。

使用稳定 hash 路由；刷新和浏览器前后退可恢复所选区，无效地址回到概览。导航当前项使用 aria-current，切页后焦点定位内容标题。切页保留草稿/对话/运行状态；流式请求不会被隐藏切页意外取消，导航或状态区域提示运行中并可返回停止。切页不自动请求上游目录和额度。

## 布局与可读性

桌面使用约 220px 侧栏与独立主内容，内容区域控制阅读宽度，常规间距 16–24px；表单标签清楚，正文约 14–16px，避免原来巨大留白挤压功能。保留明确绿色主按钮，危险动作独立标识。密钥创建后一次性展示值并提供复制，切页不得泄露到未登录视图。

390px 小屏改为紧凑可触达导航，主体无横向溢出；较宽日志表在自己的容器内滚动。键盘可操作导航/表单/弹窗，焦点样式可见，按钮禁用与加载态清楚。使用现有确认语义和错误文案，不引入无必要确认。

## 状态与验证

各区明确空、加载、失败和完成状态。账号未连接或额度缺失不能伪造可用/零用量。key 到日志导航自动带该 key 筛选；退出清理账户、密钥、日志正文、授权代码、对话等状态。验收使用隔离浏览器数据在桌面及移动宽度实际操作并截图检查；业务 API 和权限规则以 Product-Spec 为准。

## CONSOLE-TIDY-001：设置整理与稳定布局（2026-09-18）

用户要求小幅优化，保留六区、配色和现有业务操作。替代原设置页单列混排：Webshare卡片内部按账户配置和固定出口分组，宽屏左右并排、小屏上下分隔；Access和日志在足够宽时并列；本机启动指引只在不支持Webshare的Node实例展示，并置于常规设置之后。用户随后明确不需要这些描述：设置页去掉常驻解释、折叠说明及副标题，仅保留字段、当前出口/同步状态与必要操作反馈；运行限制保留在项目文档中。

反馈预留一行；设置操作也只预留一行，成功反馈使用简短文案。更长错误允许自然展开，不能裁切消息。状态标签宽度稳定，手机固定放在标题下方；当前出口预留两行。初次能力读取结束后再显示设置卡片，避免异步插入Webshare推开已有控件。页面保留滚动条空间；切页即时回到内容开始，标题焦点禁止额外滚动，异步状态更新不触发切页滚动。侧栏空消息不占空间，保留手机紧凑导航，当前选中项在横向导航中自动保持可见，不滚动主体。

验证与实际发布见 [CONSOLE-TIDY-001](tasks/CONSOLE-TIDY-001.md)。旧任务历史与原版本验收保留，不能替代本轮界面证据。

FLAREAPI-CONFIG-001 本地新版：没有默认出口时显示‘当前出口：未启用代理’；保存API key与同步节点后保持该状态，选择并测试成功后才更新出口。关闭反馈为‘已关闭代理。’，不声称直接出站。继续复用现有字段、按钮与反馈布局，不增加说明段落。


WEBSHARE-LATENCY-001：固定出口操作增加独立‘测速’按钮，只在Worker能力返回tcpTestSupported后展示。复用现有按钮/反馈空间；节点下拉项追加测得毫秒，反馈只显示TCP连接耗时与成功次数，不增加说明段落。测速期间同组禁用，结果不变更选择或当前出口。桌面及390px已验证无横向溢出。
